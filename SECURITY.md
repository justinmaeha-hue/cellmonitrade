
# Cellmoney Trade Security Policy

## Security Contact
Report security problems privately
to the Cellmoney Trade project owner.

## Customer Protection
- Never share banking passwords.
- Never share PINs or OTPs.
- Confirm payment details before transferring.
- Review screenshots before sharing them.

## Payment Security
- All orders are manually verified.
- No automatic BSP payments are processed.
- No payment receipts are stored on the site.
- Customers initiate WhatsApp sharing.

## Website Protection
- GitHub two-factor authentication is required.
- No secret keys belong in public code.
- Website source code is proprietary.
- Unauthorized reuse is prohibited as
  described in the LICENSE file.

## Limitations
This website has no secure payment
gateway or administrator backend.
