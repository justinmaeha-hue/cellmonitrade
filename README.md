
# Cellmoney Trade

Digital Mobile Top-Up Services
Papua New Guinea

## About
Cellmoney Trade is a mobile-friendly
website for requesting phone top-ups.

## Services
- Digicel top-up requests
- Vodafone top-up requests
- Telikom top-up requests
- Top-up amounts from K5 to K200
- 10% service fee
- WhatsApp customer support
- BSP payment instructions
- Payment receipt sharing

## Technology
- HTML
- CSS
- JavaScript
- GitHub Pages

## Payment Processing
All transactions require manual
confirmation and verification.
